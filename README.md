# \# 💬 FB Messenger Offline Viewer

# 

# A lightweight, high-performance desktop application built with \*\*Tauri\*\*, \*\*JavaScript\*\*, and \*\*CSS\*\* for parsing, searching, and viewing Facebook and Messenger data exports completely offline.

# 

# \---

# 

# \## ✨ Features

# 

# \* 🔒 \*\*100% Private \& Offline:\*\* All JSON processing happens strictly on your local machine. Zero data is sent to external servers.

# \* 📁 \*\*Drag-and-Drop Parsing:\*\* Effortlessly import downloaded Facebook data export folders to render structured chat threads.

# \* 🎵 \*\*Custom Waveform Audio Player:\*\* Native voice message playback complete with interactive waveform seeking and speed controls (1x, 1.25x, 1.5x, 2x).

# \* 🔍 \*\*Smart Search \& Filters:\*\* Search across individual messages, media attachments, specific dates, or participants.

# \* 🌓 \*\*Customizable UI:\*\* Built-in Dark/Light modes and font size scaling.

# \* 📊 \*\*Media Gallery:\*\* Easily filter and view all photos, videos, and attached documents across conversations.

# 

# \---

# 

# \## 🛠️ Built With

# 

# \* \*\*Framework:\*\* \[Tauri](https://tauri.app/) (Rust-backed native runtime)

# \* \*\*Frontend:\*\* Vanilla HTML5, CSS3, JavaScript (ES6+)
